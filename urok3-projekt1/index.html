Сам

Все уроки и задания, доступ к чату потока. Домашние задания преподаватель не проверяет.

С разбором

Всё из «Сам» + проверка домашних заданий и письменная обратная связь по твоим кадрам. Сертификат по итогам.

Личный

Всё из «С разбором» + три индивидуальные видео-консультации с преподавателем. Сертификат по итогам.
